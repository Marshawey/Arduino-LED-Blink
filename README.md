# Arduino-LED-Blink
First eletronic project made with an Arduino Mega consisting of a blinking LED... like all the electronic larper

# Requirement
In a first place you will need :
- Arduino Mega
- Breadboard
- Resistor
- Wires

Also Arduino IDE is mandatory to flash the Arduino Mega with the code
