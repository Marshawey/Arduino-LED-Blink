# Arduino-LED-Blink
First eletronic project made with an Arduino Mega consisting of a blinking LED... like all the electronic larper

## Requirement
In a first place you will need :
- Arduino Mega
- Breadboard
- Resistor ( 220 Ω )
- Wires ( x3 )

Also Arduino IDE is mandatory to flash the Arduino Mega with the code 

## How to use 
First open your Arduino IDE or any others IDE, then select in the settings your board here it will be the Arduino Mega. Also choose your COM port for flashing the device. Next import the Arduino_LED_project.ino in the IDE. Finnaly upload the code.

*note : The PinOUT is set on the PWM 6*
